# Framework Property Map

This file maps AoN fields to the existing PF2E framework.

Day one does not need full mapping.

## Day One

AoN Field | Framework / Token Target
---|---
creature import | NPC property type
name | token name
name | GM Name
id | AON_ID
source url | AON_URL
image url | AON_IMG_URL
full raw json | AON_JSON_RAW
metadata and parsed json | AON_JSON
image | token image if available
image | createAsset source if available
